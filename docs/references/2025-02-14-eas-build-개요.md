# EAS Build 개요

## 개요

EAS Build가 무엇인지, 왜 사용하는지, 현재 프로젝트에 어떤 영향을 끼치는지 정리합니다.

## EAS Build란?

**EAS (Expo Application Services)** 는 Expo에서 제공하는 클라우드 기반 빌드 서비스입니다.

EAS Build를 사용하면 로컬 환경에 Xcode나 Android Studio를 설치하지 않고도 iOS/Android 앱을 빌드할 수 있습니다.

## 왜 필요한가?

### 기존 방식의 문제점

| 문제 | 설명 |
|------|------|
| **로컬 빌드 환경 구축** | Xcode (macOS 필수), Android Studio 설치 필요 |
| **iOS 빌드 제한** | iOS 앱은 macOS에서만 빌드 가능 |
| **환경 차이** | 팀원마다 빌드 환경이 달라 "내 컴퓨터에서는 되는데..." 문제 발생 |
| **네이티브 모듈** | 카카오 로그인 등 네이티브 모듈 사용 시 Expo Go에서 테스트 불가 |

### EAS Build의 해결책

| 장점 | 설명 |
|------|------|
| **클라우드 빌드** | Expo 서버에서 빌드, 로컬 환경 불필요 |
| **크로스 플랫폼** | Windows/Linux에서도 iOS 앱 빌드 가능 |
| **일관된 환경** | 모든 팀원이 동일한 빌드 환경 사용 |
| **Development Build** | 네이티브 모듈 포함된 개발용 앱 생성 가능 |

## 현재 프로젝트에 미치는 영향

### 1. 카카오 로그인 때문에 필수

```
@react-native-seoul/kakao-login → 네이티브 모듈 → Expo Go에서 동작 안 함
                                                    ↓
                                          EAS Build로 Development Build 필요
```

카카오 로그인(`@react-native-seoul/kakao-login`)은 네이티브 모듈이라 **Expo Go 앱에서 테스트할 수 없습니다.** EAS Build로 커스텀 개발 앱을 만들어야 합니다.

### 2. .gitignore 영향

EAS Build를 사용하면 `ios/`, `android/` 폴더를 로컬에서 관리할 필요가 없습니다.

```gitignore
# 로컬에서 생성하지 않으므로 제외
ios/
android/
```

### 3. 프로젝트에 추가되는 파일

| 파일 | 설명 |
|------|------|
| `eas.json` | EAS Build 설정 파일 |
| `app.json` 수정 | 빌드 관련 설정 추가 |

### 4. 개발 워크플로우 변화

| 단계 | Expo Go | EAS Development Build |
|------|---------|----------------------|
| 사용 시점 | 초기 개발, UI 작업 | 네이티브 기능 테스트 |
| 빌드 필요 | ❌ | ✅ (최초 1회 + 네이티브 변경 시) |
| 카카오 로그인 | ❌ 불가 | ✅ 가능 |
| 푸시 알림 | ❌ 제한적 | ✅ 가능 |

## EAS Build 종류

| 타입 | 용도 | 설명 |
|------|------|------|
| **Development** | 개발용 | 개발자 도구 포함, 디버깅 가능 |
| **Preview** | 테스트용 | 내부 테스터 배포용 |
| **Production** | 출시용 | 앱스토어 제출용 |

## 비용

| 플랜 | 빌드 | 비용 |
|------|------|------|
| Free | 월 30회 | 무료 |
| Production | 무제한 | $99/월 |

> **참고**: 개인 프로젝트나 소규모 팀은 Free 플랜으로 충분합니다.

## 기본 명령어

```bash
# EAS CLI 설치
npm install -g eas-cli

# EAS 로그인
eas login

# EAS 프로젝트 초기화
eas build:configure

# Development Build (iOS)
eas build --profile development --platform ios

# Development Build (Android)
eas build --profile development --platform android

# Production Build
eas build --profile production --platform all
```

## eas.json 예시

```json
{
  "cli": {
    "version": ">= 5.0.0"
  },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal"
    },
    "preview": {
      "distribution": "internal"
    },
    "production": {}
  },
  "submit": {
    "production": {}
  }
}
```
