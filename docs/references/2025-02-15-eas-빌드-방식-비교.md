# EAS 빌드 방식 비교: 클라우드 vs 로컬

## 개요

EAS Build는 클라우드 빌드와 로컬 빌드 두 가지 방식을 지원합니다. 각 방식의 차이점과 언제 어떤 방식을 사용해야 하는지 정리합니다.

## 클라우드 빌드 vs 로컬 빌드

| 항목 | 클라우드 빌드 | 로컬 빌드 |
|------|-------------|----------|
| 명령어 | `eas build` | `eas build --local` |
| 빌드 위치 | EAS 서버 | 내 Mac |
| 빌드 시간 | 15-30분 (대기열 포함) | 5-10분 |
| 인터넷 | 필수 | 초기 설정 후 불필요 |
| macOS | 불필요 | **필수** (iOS 빌드) |
| Apple 인증 | EAS가 처리 | 로컬 Keychain 사용 |
| 비용 | 무료 플랜 제한 있음 | 무료 |

## 로컬 빌드 사용법

```bash
# iOS 시뮬레이터용 로컬 빌드
eas build --profile development --platform ios --local

# iOS 실제 기기용 로컬 빌드
eas build --profile development --platform ios --local --device
```

## 로컬 빌드 요구사항

| 요구사항 | 설치 방법 |
|----------|----------|
| macOS | iOS 빌드는 Mac에서만 가능 |
| Xcode | App Store에서 설치 |
| Command Line Tools | `xcode-select --install` |
| CocoaPods | `sudo gem install cocoapods` |
| Fastlane (선택) | `brew install fastlane` |

## 로컬 빌드의 인증서 처리

로컬 빌드 시 인증서는 **Mac Keychain**에서 직접 사용합니다:

```
[클라우드 빌드]
EAS 서버 ──▶ EAS에 저장된 인증서 사용 ──▶ Apple 서버 인증 필요

[로컬 빌드]
내 Mac ──▶ Keychain의 인증서 직접 사용 ──▶ 추가 인증 불필요
```

**첫 로컬 빌드 시:**
1. EAS가 Keychain에서 인증서 검색
2. 없으면 자동 생성 또는 EAS 서버에서 다운로드
3. Keychain에 저장 후 빌드

## 언제 어떤 방식을 사용하는가?

| 상황 | 권장 방식 | 이유 |
|------|----------|------|
| 빠른 개발 테스트 | **로컬 빌드** | 대기열 없이 즉시 빌드 |
| 네이티브 코드 디버깅 | **로컬 빌드** | 빌드 과정 직접 확인 가능 |
| CI/CD 파이프라인 | 클라우드 빌드 | macOS 환경 불필요 |
| 팀 공유 빌드 | 클라우드 빌드 | 일관된 빌드 환경 |
| Windows/Linux 개발 | 클라우드 빌드 | 로컬 빌드 불가능 |

## eas.json 빌드 프로필 설정

### 기본 프로필

```json
{
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal",
      "ios": {
        "simulator": true
      }
    },
    "preview": {
      "distribution": "internal"
    },
    "production": {}
  }
}
```

### 로컬 빌드 최적화 설정 (선택)

시뮬레이터와 실제 기기 빌드를 분리:

```json
{
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal",
      "ios": {
        "simulator": true,
        "buildConfiguration": "Debug"
      }
    },
    "development:device": {
      "developmentClient": true,
      "distribution": "internal",
      "ios": {
        "simulator": false,
        "buildConfiguration": "Debug"
      }
    }
  }
}
```

```bash
# 시뮬레이터용
eas build --profile development --platform ios --local

# 실제 기기용
eas build --profile development:device --platform ios --local
```

## 빌드 프로필 설명

| 프로필 | 용도 | 특징 |
|--------|------|------|
| `development` | 개발 중 테스트 | 개발 클라이언트, 핫 리로드 |
| `preview` | 내부 테스트 배포 | 프로덕션 유사, 내부 배포 |
| `production` | 스토어 배포 | 최적화, 서명 포함 |
