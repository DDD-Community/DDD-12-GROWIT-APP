# WebView 설정 가이드

## 개요

React Native WebView 컴포넌트 설정 시 발생할 수 있는 이슈와 해결 방법을 정리합니다.

## 주요 설정

### 기본 WebView 설정

```typescript
<WebView
  source={{ uri }}
  javaScriptEnabled={true}
  domStorageEnabled={true}
  sharedCookiesEnabled={false}
  webviewDebuggingEnabled={__DEV__}
  bounces={false}
  overScrollMode="never"
/>
```

## 이슈별 해결 방법

### 1. Sandbox 에러

**증상**:
```
Error loading page
Domain: WebKitInternal
Error Code: 0
Description: Ignoring request to load this main resource because is outside the sandbox
```

**원인**: EAS 빌드 시 WebView가 외부 URL을 로드하지 못하는 보안 제한

**해결**:
```typescript
<WebView
  originWhitelist={['*']}
  // 또는 특정 도메인만 허용
  originWhitelist={['https://*', 'http://*']}
/>
```

### 2. 비디오 전체화면 자동 전환 방지

**증상**: WebView 내 비디오 재생 시 자동으로 전체화면 플레이어로 전환됨

**해결**:
```typescript
<WebView
  allowsInlineMediaPlayback={true}      // 인라인 재생 허용 (iOS)
  mediaPlaybackRequiresUserAction={false} // 자동 재생 허용
  allowsFullscreenVideo={false}          // 전체화면 전환 비활성화
/>
```

### 3. 앱 ↔ 웹 메시지 통신

```typescript
// 웹에서 메시지 수신
const handleMessage = (event: WebViewMessageEvent) => {
  const data = JSON.parse(event.nativeEvent.data);
  // 메시지 처리
};

<WebView
  onMessage={handleMessage}
/>
```

## 전체 설정 예시

### AuthWebView (인증용)

```typescript
export const AuthWebView = ({ uri }: Props) => {
  return (
    <WebView
      source={{ uri }}
      style={styles.webview}
      onMessage={handleMessage}
      javaScriptEnabled={true}
      domStorageEnabled={true}
      sharedCookiesEnabled={false}
      webviewDebuggingEnabled={__DEV__}
      bounces={false}
      overScrollMode="never"
      originWhitelist={['*']}
      allowsInlineMediaPlayback={true}
    />
  );
};
```

### MainWebView (메인 콘텐츠용)

```typescript
export const MainWebView = ({ uri, injectedJavaScript, onMessage }: Props) => {
  return (
    <WebView
      source={{ uri }}
      style={styles.webview}
      javaScriptEnabled={true}
      domStorageEnabled={true}
      sharedCookiesEnabled={false}
      webviewDebuggingEnabled={__DEV__}
      bounces={false}
      overScrollMode="never"
      originWhitelist={['*']}
      injectedJavaScript={injectedJavaScript}
      onMessage={onMessage}
      allowsInlineMediaPlayback={true}
      mediaPlaybackRequiresUserAction={false}
      allowsFullscreenVideo={false}
    />
  );
};
```

## 주요 Props 설명

| Prop | 설명 |
|------|------|
| `originWhitelist` | 로드 허용할 URL 패턴 |
| `allowsInlineMediaPlayback` | iOS에서 인라인 비디오 재생 허용 |
| `mediaPlaybackRequiresUserAction` | 미디어 자동 재생 여부 |
| `allowsFullscreenVideo` | 전체화면 비디오 허용 여부 |
| `webviewDebuggingEnabled` | Safari/Chrome 개발자 도구 디버깅 허용 |
| `bounces` | iOS 바운스 효과 |
| `overScrollMode` | Android 오버스크롤 모드 |
