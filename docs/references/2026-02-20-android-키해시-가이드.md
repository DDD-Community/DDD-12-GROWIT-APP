# Android 키 해시 (Key Hash) 가이드

## 키 해시란?

**키 해시**는 안드로이드 앱의 서명 인증서를 SHA-1으로 해시한 후 Base64 인코딩한 값입니다.

### 왜 필요한가?

카카오 서버가 **"이 요청이 진짜 등록된 앱에서 온 것인지"** 확인하기 위해 사용합니다.

```
[앱에서 로그인 요청]
       ↓
[카카오 서버]
  "이 앱의 키 해시가 등록된 것과 일치하는가?"
       ↓
  일치 → 로그인 허용
  불일치 → 거부 (KEYSTORE_NOT_FOUND 에러)
```

### 왜 안드로이드만 필요한가?

| 플랫폼 | 앱 식별 방법 |
|--------|-------------|
| iOS | 번들 ID (Apple이 앱스토어에서 검증) |
| Android | 키 해시 (앱 서명 인증서 기반) |

안드로이드는 APK를 어디서든 설치할 수 있어서, 패키지명만으로는 위조 앱을 구분할 수 없습니다. 키 해시는 앱 서명 인증서에서 생성되므로 위조가 불가능합니다.

---

## 환경별 키 해시

| 환경 | 사용 시점 | 키 해시 |
|------|----------|--------|
| 로컬 개발 (debug) | `npx expo run:android` | `~/.android/debug.keystore`에서 생성 |
| EAS Development Build | `eas build --profile development` | EAS가 관리하는 서명 키에서 생성 |
| EAS Production Build | `eas build --profile production` | 릴리즈용 키스토어에서 생성 |

**각 환경의 키 해시가 다르므로**, 카카오 개발자 콘솔에 모두 등록해야 합니다.

---

## 환경별 생성 방법

### 1. 로컬 개발 (Debug)

**사용 시점:** 로컬에서 `npx expo run:android` 실행 시

```bash
keytool -exportcert -alias androiddebugkey \
  -keystore ~/.android/debug.keystore \
  -storepass android -keypass android \
  | openssl sha1 -binary | openssl base64
```

> 기본 비밀번호는 `android`입니다.

---

### 2. EAS Development Build

**사용 시점:** `eas build --profile development` 로 빌드한 앱

#### Credential이 없는 경우 (처음 빌드)

```bash
eas build --profile development --platform android
```

빌드 과정에서 아래 질문이 나옵니다:

```
? Generate a new Android Keystore? (Y/n)
```

**Y**를 선택하면 EAS가 키스토어를 자동 생성하고 관리합니다.

#### 빌드 후 키 해시 확인

```bash
eas credentials
```

```
? Select platform: Android
? Select profile: development
? What do you want to do?
  > View credentials
```

출력 예시:
```
Keystore
  Key Alias: xxxxxxxx
  MD5 Fingerprint: XX:XX:XX:...
  SHA1 Fingerprint: AA:BB:CC:DD:EE:FF:00:11:22:33:44:55:66:77:88:99:AA:BB:CC:DD
  SHA256 Fingerprint: XX:XX:XX:...
```

---

### 3. EAS Production Build

**사용 시점:** `eas build --profile production` 또는 스토어 배포 앱

```bash
eas credentials
# Android > production 프로필 선택
# 위와 동일하게 SHA-1 확인 후 변환
```

---

## SHA-1 → 키 해시 변환

EAS에서 SHA-1 fingerprint (콜론 포함)를 받으면:

```bash
# 예: AA:BB:CC:DD:... 형태
echo "AA:BB:CC:DD:EE:FF:00:11:22:33:44:55:66:77:88:99:AA:BB:CC:DD" \
  | tr -d ':' | xxd -r -p | openssl base64
```

출력된 값이 카카오에 등록할 **키 해시**입니다.

---

## 카카오 개발자 콘솔에 등록

**등록 위치:**
1. [카카오 개발자 콘솔](https://developers.kakao.com/) 접속
2. 내 애플리케이션 선택
3. 앱 설정 → 플랫폼 → Android
4. 키 해시 추가

| 환경 | 등록 필요 여부 |
|------|--------------|
| Debug (로컬) | 개발 중 테스트용 |
| Development | Development Build 테스트용 |
| Production | 스토어 배포 전 필수 |

## 요약

| 단계 | 명령어 |
|------|--------|
| 1. 빌드 (credential 자동 생성) | `eas build --profile development --platform android` |
| 2. SHA1 확인 | `eas credentials` → View credentials |
| 3. 키 해시 변환 | `echo "SHA1" \| tr -d ':' \| xxd -r -p \| openssl base64` |
| 4. 카카오에 등록 | 개발자 콘솔 → 플랫폼 → Android → 키 해시 추가 |
