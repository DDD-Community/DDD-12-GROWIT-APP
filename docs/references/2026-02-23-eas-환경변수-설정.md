# EAS 환경변수 설정 가이드

## 개요

EAS Build에서 환경별(development, preview, production) 환경변수를 설정하는 방법을 정리합니다.
로컬 개발 시 `.env` 파일로 관리하던 환경변수를 EAS 클라우드 빌드에서도 사용할 수 있도록 구성합니다.

## 환경변수 설정 방식

### 1. EAS Secrets (권장)

민감한 정보(API URL, 키 등)는 EAS Secrets로 관리합니다.

```bash
# Secret 생성
eas secret:create --name VARIABLE_NAME --value "value"

# Secret 목록 확인
eas secret:list

# Secret 삭제
eas secret:delete VARIABLE_NAME
```

### 2. eas.json에서 환경변수 참조

`eas.json`의 `env` 블록에서 `${VARIABLE_NAME}` 구문으로 EAS Secrets를 참조합니다:

```json
{
  "build": {
    "development": {
      "env": {
        "EXPO_PUBLIC_WEB_URL": "${EXPO_PUBLIC_WEB_URL_DEV}",
        "EXPO_PUBLIC_API_URL": "${EXPO_PUBLIC_API_URL_DEV}"
      }
    },
    "production": {
      "env": {
        "EXPO_PUBLIC_WEB_URL": "${EXPO_PUBLIC_WEB_URL_PROD}",
        "EXPO_PUBLIC_API_URL": "${EXPO_PUBLIC_API_URL_PROD}"
      }
    }
  }
}
```

## 프로젝트 설정 예시

### EAS Secrets 등록

```bash
# DEV 환경
eas secret:create --name EXPO_PUBLIC_API_URL_DEV --value "https://api.grow-it.me/"
eas secret:create --name EXPO_PUBLIC_WEB_URL_DEV --value "https://devweb.grow-it.me/"

# PROD 환경
eas secret:create --name EXPO_PUBLIC_API_URL_PROD --value "https://api.grow-it.me/"
eas secret:create --name EXPO_PUBLIC_WEB_URL_PROD --value "https://grow-it.me/"
```

### eas.json 설정

```json
{
  "cli": {
    "version": ">= 18.0.1",
    "appVersionSource": "remote"
  },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal",
      "ios": {
        "simulator": true
      },
      "env": {
        "EXPO_PUBLIC_WEB_URL": "${EXPO_PUBLIC_WEB_URL_DEV}",
        "EXPO_PUBLIC_API_URL": "${EXPO_PUBLIC_API_URL_DEV}"
      }
    },
    "preview": {
      "distribution": "internal",
      "env": {
        "EXPO_PUBLIC_WEB_URL": "${EXPO_PUBLIC_WEB_URL_DEV}",
        "EXPO_PUBLIC_API_URL": "${EXPO_PUBLIC_API_URL_DEV}"
      }
    },
    "production": {
      "autoIncrement": true,
      "env": {
        "EXPO_PUBLIC_WEB_URL": "${EXPO_PUBLIC_WEB_URL_PROD}",
        "EXPO_PUBLIC_API_URL": "${EXPO_PUBLIC_API_URL_PROD}"
      }
    }
  }
}
```

### 앱에서 환경변수 사용

```typescript
// src/constants/index.ts
export const WEB_URL = process.env.EXPO_PUBLIC_WEB_URL!;
export const API_URL = process.env.EXPO_PUBLIC_API_URL!;
```

## 환경변수 디버깅

빌드 시 환경변수가 제대로 적용되었는지 확인하려면:

```typescript
// 앱 코드에서 확인
console.log('WEB_URL:', process.env.EXPO_PUBLIC_WEB_URL);
console.log('API_URL:', process.env.EXPO_PUBLIC_API_URL);
```

## 주의사항

1. **EXPO_PUBLIC_ 접두사**: Expo에서 클라이언트로 노출할 환경변수는 반드시 `EXPO_PUBLIC_` 접두사가 필요
2. **빌드 타임 주입**: 환경변수는 빌드 시점에 주입되므로, 변경 시 재빌드 필요
3. **로컬 개발**: 로컬에서는 `.env` 파일 사용, EAS 빌드에서는 EAS Secrets 사용
