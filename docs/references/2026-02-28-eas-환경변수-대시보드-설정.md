# EAS 환경변수 대시보드 설정

## 개요

EAS 대시보드(expo.dev)에서 환경변수를 직접 관리하는 방법을 정리합니다. eas.json에 값을 직접 작성하지 않고, EAS 서비스에서 환경별로 변수를 설정할 수 있습니다.

## 환경(Environment) 개념

EAS는 세 가지 기본 환경을 제공합니다:

| 환경 | 빌드 프로필 | 용도 |
|------|------------|------|
| `development` | development | 개발용 빌드 |
| `preview` | preview | 내부 테스트용 |
| `production` | production | 스토어 배포용 |

> 빌드 시 `--profile` 옵션에 따라 해당 환경의 변수가 자동으로 주입됩니다.

---

## EAS 대시보드에서 환경변수 설정

### 1. 대시보드 접속

1. [expo.dev](https://expo.dev) 접속 및 로그인
2. **Projects** → 프로젝트 선택

### 2. Environment Variables 메뉴

1. 좌측 메뉴에서 **Project settings** 클릭
2. **Environment variables** 선택

### 3. 변수 추가

1. **Add Variable** 버튼 클릭
2. 다음 정보 입력:

| 필드 | 설명 |
|------|------|
| **Name** | 변수명 (예: `EXPO_PUBLIC_API_URL`) |
| **Value** | 값 (예: `https://api.example.com/`) |
| **Environments** | 적용할 환경 선택 (복수 선택 가능) |
| **Visibility** | plaintext / sensitive / secret |

3. **Add** 버튼 클릭

### 4. 변수 수정/삭제

- 등록된 변수 우측 **...** 메뉴 → **Edit** 또는 **Delete**

---

## Visibility 옵션

| 옵션 | 설명 | 빌드 로그 | 사용 예시 |
|------|------|----------|----------|
| `plaintext` | 값이 그대로 노출됨 | 노출됨 | 일반 설정값 |
| `sensitive` | 값이 마스킹됨 | `***` 표시 | API 엔드포인트 |
| `secret` | 완전히 숨겨짐 | 표시 안됨 | API Key, 비밀번호 |

## 빌드 환경별 설정 예시

### 예시: API URL을 환경별로 다르게 설정

#### 1. development 환경

| Name | Value | Environments | Visibility |
|------|-------|--------------|------------|
| `EXPO_PUBLIC_API_URL` | `https://dev-api.example.com/` | development | plaintext |
| `EXPO_PUBLIC_WEB_URL` | `https://dev.example.com/` | development | plaintext |

#### 2. preview 환경

| Name | Value | Environments | Visibility |
|------|-------|--------------|------------|
| `EXPO_PUBLIC_API_URL` | `https://staging-api.example.com/` | preview | plaintext |
| `EXPO_PUBLIC_WEB_URL` | `https://staging.example.com/` | preview | plaintext |

#### 3. production 환경

| Name | Value | Environments | Visibility |
|------|-------|--------------|------------|
| `EXPO_PUBLIC_API_URL` | `https://api.example.com/` | production | plaintext |
| `EXPO_PUBLIC_WEB_URL` | `https://www.example.com/` | production | plaintext |

### 예시: 민감한 정보 (모든 환경 동일)

| Name | Value | Environments | Visibility |
|------|-------|--------------|------------|
| `KAKAO_NATIVE_APP_KEY` | `abc123...` | development, preview, production | secret |

> 하나의 변수를 여러 환경에 동시에 적용할 수 있습니다.

## eas.json과 연동

EAS 대시보드에서 설정한 변수는 eas.json의 `env` 섹션과 함께 사용할 수 있습니다.

### 방법 1: 대시보드 변수만 사용

eas.json에 `env` 섹션 없이 대시보드 변수만 사용:

```json
{
  "build": {
    "production": {
      "autoIncrement": true
    }
  }
}
```

### 방법 2: 대시보드 변수 참조

eas.json에서 대시보드 변수를 참조:

```json
{
  "build": {
    "production": {
      "env": {
        "EXPO_PUBLIC_API_URL": "${EXPO_PUBLIC_API_URL_PROD}"
      }
    }
  }
}
```

> `${변수명}` 문법으로 대시보드에 등록된 변수를 참조할 수 있습니다.

## 같은 이름의 환경변수 처리

EAS에서 **같은 이름의 환경변수를 여러 환경에 등록**해도 문제가 없습니다.

### 동작 방식

EAS는 환경변수를 `(Name, Environment)` 조합으로 관리합니다. 따라서:

| Name | Environment | Value |
|------|-------------|-------|
| `EXPO_PUBLIC_API_URL` | development | `https://dev-api.example.com/` |
| `EXPO_PUBLIC_API_URL` | preview | `https://staging-api.example.com/` |
| `EXPO_PUBLIC_API_URL` | production | `https://api.example.com/` |

위와 같이 **같은 이름으로 환경별로 다른 값**을 설정할 수 있습니다.

### 빌드 시 적용 규칙

```bash
# development 빌드 → development 환경변수 적용
eas build --profile development

# preview 빌드 → preview 환경변수 적용
eas build --profile preview

# production 빌드 → production 환경변수 적용
eas build --profile production
```

빌드 프로필(`--profile`)에 따라 해당 환경의 변수만 주입됩니다.

### 주의사항

- **동일 환경 내 중복 이름은 불가**: 같은 환경에 같은 이름의 변수를 두 번 등록할 수 없습니다.
- **환경 간 중복은 허용**: 서로 다른 환경에 같은 이름의 변수를 등록하는 것은 정상적인 사용법입니다.

## CLI로 환경변수 확인

```bash
# 환경별 변수 목록 확인
eas env:list --environment development
eas env:list --environment preview
eas env:list --environment production

# 로컬 개발용 .env 파일 생성
eas env:pull --environment development
```

## 코드에서 환경변수 사용

### 클라이언트 코드 (React Native)

`EXPO_PUBLIC_` 접두사가 있는 변수만 클라이언트 코드에서 접근 가능:

```typescript
// 사용 가능
const apiUrl = process.env.EXPO_PUBLIC_API_URL;
const webUrl = process.env.EXPO_PUBLIC_WEB_URL;

// 사용 불가 (undefined)
const kakaoKey = process.env.KAKAO_NATIVE_APP_KEY; // undefined
```

### app.config.js (빌드 설정)

`EXPO_PUBLIC_` 접두사가 없는 변수는 app.config.js에서만 접근 가능:

```javascript
// app.config.js
export default {
  expo: {
    plugins: [
      [
        '@react-native-seoul/kakao-login',
        {
          kakaoAppKey: process.env.KAKAO_NATIVE_APP_KEY, // 접근 가능
        },
      ],
    ],
  },
};
```
