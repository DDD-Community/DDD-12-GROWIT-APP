# 참고 자료 (References)

## 개요

프로젝트 진행 중 조사하거나 학습한 내용을 정리하는 폴더입니다.

## 파일 네이밍 규칙

```
{YYYY-MM-DD}-{한국어파일이름}.md
```

### 예시

| 파일명 | 설명 |
|--------|------|
| `2025-02-14-expo-라우터-설정방법.md` | expo-router 설정 관련 조사 내용 |
| `2025-02-15-애플-로그인-심사기준.md` | Apple 로그인 앱스토어 심사 관련 정보 |
| `2025-02-16-카카오-로그인-설정.md` | 카카오 로그인 설정 방법 |
| `2025-02-17-웹뷰-브릿지-통신.md` | 웹뷰 ↔ 앱 통신 방법 |
