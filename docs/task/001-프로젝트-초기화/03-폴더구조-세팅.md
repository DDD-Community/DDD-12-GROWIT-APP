# 03. 폴더구조 세팅

## 목표

프로젝트의 폴더 구조를 정의하고 `src/` 기반 구조로 세팅합니다.

## 상태

⬜ 대기

## 폴더 구조

```
DDD-12-GROWIT-APP/
├── growit-mobile/
│   ├── src/                        # 소스 코드
│   │   ├── app/                    # expo-router 화면 (파일 기반 라우팅)
│   │   │   ├── _layout.tsx         # 루트 레이아웃 (인증 체크 및 리다이렉트)
│   │   │   ├── (auth)/             # 비로그인 사용자 그룹
│   │   │   │   └── login.tsx       # /login (로그인 화면)
│   │   │   ├── (main)/             # 로그인 사용자 그룹
│   │   │   │   ├── _layout.tsx
│   │   │   │   └── index.tsx       # / (웹뷰 화면)
│   │   │   └── +not-found.tsx      # 404 화면
│   │   │
│   │   ├── components/             # 재사용 UI 컴포넌트
│   │   │   ├── WebViewContainer.tsx
│   │   │   ├── AppleLoginButton.tsx
│   │   │   └── KakaoLoginButton.tsx
│   │   │

│   │   │   ├── auth.ts             # 인증 로직 (Apple/Kakao)
│   │   │   ├── useAuth.ts          # 인증 상태 훅
│   │   │   └── notification.ts     # 푸시 알림 (추후)
│   │   │
│   │   └── constants/              # 상수 정의
│   │       └── index.ts
│   │
│   ├── assets/                     # 정적 리소스 (이미지, 폰트)
│   │   ├── fonts/
│   │   └── images/
│   │
│   ├── app.json                    # Expo 설정
│   ├── babel.config.js             # Babel 설정
│   ├── tsconfig.json               # TypeScript 설정
│   └── package.json                # 프로젝트 의존성
│
├── docs/                           # 프로젝트 문서
│
└── README.md
```

## 앱 화면 흐름

```
앱 실행
    ↓
_layout.tsx (인증 상태 체크)
    ↓
┌─────────────────────────────────────┐
│  로그인 안됨       │    로그인 됨     │
│       ↓           │        ↓        │
│  (auth)/login.tsx │  (main)/index   │
│  로그인 화면       │  웹뷰 화면       │
└─────────────────────────────────────┘
```

## 작업 절차

### 1. src 폴더 구조 생성

```bash
cd growit-mobile
mkdir -p src/app/\(auth\) src/app/\(main\) src/components src/lib src/constants
```

### 2. 기존 파일 이동

> **참고**: `default` 템플릿 생성 후, 기존 `app/`, `components/` 등을 `src/` 안으로 이동합니다.

```bash
mv app src/
mv components src/
mv constants src/
mv hooks src/lib/
```

### 3. app.json 설정 추가

`src/app/` 폴더를 expo-router가 인식하도록 설정합니다.

```json
{
  "expo": {
    "scheme": "growit-mobile",
    "experiments": {
      "typedRoutes": true
    }
  }
}
```

### 4. tsconfig.json 경로 설정

```json
{
  "extends": "expo/tsconfig.base",
  "compilerOptions": {
    "strict": true,
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
      "@components/*": ["./src/components/*"],
      "@lib/*": ["./src/lib/*"],
      "@constants/*": ["./src/constants/*"],
      "@assets/*": ["./assets/*"]
    }
  },
  "include": ["**/*.ts", "**/*.tsx", ".expo/types/**/*.ts", "expo-env.d.ts"]
}
```

> **참고**: `assets/`는 `src/` 외부에 위치합니다. `app.json`에서 아이콘/스플래시 경로가 `./assets/`를 참조하므로 루트에 유지하고, `@assets/*` 별칭으로 접근합니다.

### 5. 기본 파일 생성

#### src/constants/index.ts

```typescript

export const AUTH_PROVIDERS = {

```

## 폴더별 역할

| 폴더 | 역할 | 경로 별칭 |
|------|------|----------|
| `src/app/` | expo-router 화면 (파일 기반 라우팅) | - |
| `src/app/(auth)/` | 비로그인 사용자용 화면 그룹 | - |
| `src/app/(main)/` | 로그인 사용자용 화면 그룹 | - |
| `src/components/` | 재사용 UI 컴포넌트 | `@components/*` |
| `src/lib/` | 비즈니스 로직, 커스텀 훅 | `@lib/*` |
| `src/constants/` | 상수, 설정값 | `@constants/*` |
| `assets/` | 이미지, 폰트 등 정적 파일 | `@assets/*` |

> **주의**: `assets/`는 `src/` 외부에 있으므로 `@/assets`가 아닌 `@assets`로 접근합니다.
