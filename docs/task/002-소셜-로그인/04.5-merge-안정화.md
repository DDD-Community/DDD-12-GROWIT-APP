# 04.5. Merge 안정화

## 목표

팀원 브랜치 merge 후 프로젝트 안정화 및 Unmatched Route 에러 해결

## 상태

✅ 완료

## 문제 분석

### Unmatched Route 에러

`_layout.tsx`에서 `name="index"` 라우트를 참조하지만, `src/app/index.tsx` 파일이 존재하지 않음.

```
src/app/
├── _layout.tsx          ← name="index" 참조
├── (auth)/
│   ├── _layout.tsx
│   └── login.tsx
└── index.tsx            ← ❌ 파일 없음 (Unmatched Route)
```

**원인**: merge 과정에서 `(tabs)/` 폴더가 삭제되면서 루트 `index.tsx`도 함께 삭제됨

## 작업 절차

### 1. 루트 index.tsx 생성

임시 메인 화면 생성 (추후 WebView로 교체 예정)

```typescript
// src/app/index.tsx
import { View, Text, StyleSheet } from 'react-native';

export default function HomeScreen() {
  return (
    <View style={styles.container}>
      <Text style={styles.text}>GrowIt</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
    backgroundColor: '#121212',
  },
  text: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#ffffff',
  },
});
```

### 2. _layout.tsx 라우팅 확인

현재 `_layout.tsx`가 올바르게 두 라우트를 선언하고 있는지 확인:

```typescript
<Stack>
  <Stack.Screen name="index" options={{ headerShown: false }} />
  <Stack.Screen name="(auth)" options={{ headerShown: false }} />
</Stack>
```
