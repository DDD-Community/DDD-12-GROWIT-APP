# 07.1. 로그인 시 user 정보 누락 버그

## 상태

🔄 진행중

## 문제 상황

WebView에서 이메일 로그인 성공 후 `SYNC_TOKEN_TO_APP` 메시지를 받아 토큰을 저장하지만, **메인 화면으로 이동하지 않고** 로그인 화면에 머무는 문제가 발생.

### 증상

1. WebView에서 로그인 성공
2. `SYNC_TOKEN_TO_APP` 메시지 수신
3. 토큰 저장 (`login()` 호출)
4. `router.replace('/(main)')` 실행
5. **메인 화면으로 이동 안됨** → `index.tsx` (GrowIt 페이지)로 이동
6. 다시 이메일 로그인 버튼 클릭 시 WebView가 토큰 대기 상태 (preload)

---

## 원인 분석

### 1차 원인: user 정보 필수 조건 (해결됨)

`AuthWebView.tsx`에서 `SYNC_TOKEN_TO_APP` 처리 시 `user` 정보 검증 조건이 문제:

```typescript
// AuthWebView.tsx (수정 전)
if (payload?.accessToken && payload?.refreshToken && payload?.user) {  // ⚠️ user 필수
```

**해결:** `user` 조건 제거, `login()` 메서드에서 user 파라미터 제거

### 2차 원인: useAuth 상태 미공유 문제

`useAuth` 훅이 **각 컴포넌트에서 독립적인 상태**를 가짐:

```
AuthWebView.tsx     → useAuth() → 자체 state (로그인 성공, isAuthenticated: true)
_layout.tsx         → useAuth() → 자체 state (여전히 isAuthenticated: false)
```

**문제 흐름:**

1. `AuthWebView`에서 `login()` 호출 → `AuthWebView`의 `useAuth` 상태만 업데이트
2. `router.replace('/(main)')` 실행
3. `_layout.tsx`의 `useAuth`는 여전히 `isAuthenticated: false`
4. `_layout.tsx`의 useEffect 조건에 해당 안됨 → `index.tsx`로 이동

```typescript
// _layout.tsx
useEffect(() => {
  if (isLoading) return;

  const inAuthGroup = segments[0] === '(auth)';

  if (!isAuthenticated && !inAuthGroup) {
    router.replace('/(auth)/login');
  } else if (isAuthenticated && inAuthGroup) {
    router.replace('/(main)');
  }
  // ⚠️ isAuthenticated && !inAuthGroup 케이스: 아무것도 안함 → index.tsx 유지
}, [isLoading, isAuthenticated, segments, router]);
```

## 해결 방안

### 1차 해결: user 파라미터 제거 (완료)

`AuthState`에서 `user` 제거, `login()` 메서드에서 토큰만 받도록 수정:

```typescript
// useAuth.ts (현재)
export interface AuthState {
  isLoading: boolean;
  isAuthenticated: boolean;
  tokens: Tokens | null;
}

const login = useCallback(async (tokens: Tokens) => {
  await tokenStorage.saveTokens(tokens);
  setState({
    isLoading: false,
    isAuthenticated: true,
    tokens,
  });
}, []);
```

### 2차 해결: Context 기반 전역 상태 공유 (진행중)

`useAuth`를 Context Provider로 변경하여 앱 전체에서 동일한 상태를 공유:

```typescript
// AuthContext.tsx (신규)
const AuthContext = createContext<AuthState & AuthActions | null>(null);

export const AuthProvider = ({ children }: { children: React.ReactNode }) => {
  const [state, setState] = useState<AuthState>({
    isLoading: true,
    isAuthenticated: false,
    tokens: null,
  });

  // ... login, logout, refreshAuth 구현

  return (
    <AuthContext.Provider value={{ ...state, login, logout, refreshAuth }}>
      {children}
    </AuthContext.Provider>
  );
};

export const useAuth = () => {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error('useAuth must be used within AuthProvider');
  }
  return context;
};
```

```typescript
// _layout.tsx (수정)
export default function RootLayout() {
  return (
    <AuthProvider>
      <RootLayoutNav />
    </AuthProvider>
  );
}
```

**예상 결과:**

```
AuthWebView.tsx     → useAuth() ─┐
                                 ├─→ AuthContext (공유 상태)
_layout.tsx         → useAuth() ─┘
```

`AuthWebView`에서 `login()` 호출 시 `_layout.tsx`도 동일한 상태를 참조하여 `isAuthenticated: true`로 업데이트됨.
