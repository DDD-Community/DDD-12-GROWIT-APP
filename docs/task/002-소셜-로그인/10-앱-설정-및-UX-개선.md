### 2. 2단계 Splash 화면 구현

#### 문제 상황

기존에는 단일 splash 이미지가 표시되었으나, 다음과 같은 요구사항이 있었습니다:

1. 앱 시작 시 아이콘/로고를 먼저 표시
2. 이후 화면에 꽉 차는 splash 이미지를 표시

#### 해결 방안

2단계 splash 화면을 구현했습니다:

**1단계: 네이티브 Splash (app.config.js)**

```javascript
// app.config.js
[
  'expo-splash-screen',
  {
    image: './assets/app/icon.png',    // 앱 아이콘
    resizeMode: 'contain',              // 중앙에 비율 유지
    backgroundColor: '#000000',
  },
],
```

**2단계: 커스텀 Splash (_layout.tsx)**

```typescript
// src/app/_layout.tsx

import * as SplashScreen from 'expo-splash-screen';

// 앱 시작 시 네이티브 splash 화면 유지
SplashScreen.preventAutoHideAsync();

function RootLayoutNav() {
  const [nativeSplashHidden, setNativeSplashHidden] = useState(false);
  const [customSplashVisible, setCustomSplashVisible] = useState(true);
  const [appIsReady, setAppIsReady] = useState(false);

  // 1단계: 네이티브 splash 숨기고 커스텀 splash 표시
  useEffect(() => {
    async function hideNativeSplash() {
      if (!isLoading) {
        await SplashScreen.hideAsync();
        setNativeSplashHidden(true);
      }
    }
    hideNativeSplash();
  }, [isLoading]);

  // 2단계: 커스텀 splash 1.8초 후 숨기기
  useEffect(() => {
    if (nativeSplashHidden) {
      const timer = setTimeout(() => {
        setCustomSplashVisible(false);
        setAppIsReady(true);
      }, 1800);
      return () => clearTimeout(timer);
    }
  }, [nativeSplashHidden]);

  // 커스텀 splash 화면 (화면 꽉 채우는 이미지)
  if (customSplashVisible) {
    return (
      <View style={styles.splashContainer}>
        <Image
          source={require('../../assets/app/splash.png')}
          style={styles.splashImage}
          resizeMode="cover"
        />
      </View>
    );
  }

  // ... 나머지 라우팅 로직
}
```

#### Splash resizeMode 옵션

| 옵션 | 동작 |
|------|------|
| `contain` | 이미지 비율 유지, 화면에 맞춤 (여백 발생) |
| `cover` | 이미지 비율 유지, 화면 꽉 채움 (잘릴 수 있음) |
| `native` | 플랫폼 기본값 사용 (contain과 유사) |

#### 플로우

```
앱 시작 → 아이콘 로고 (네이티브) → 꽉 찬 이미지 (커스텀, 1.8초) → 로그인/메인 화면
```

### 3. oauth-signup 화면 Safe Area 적용

#### 변경 사항

`oauth-signup.tsx`에 `(main)/index.tsx`와 동일한 safe area 처리 방식을 적용했습니다.

**Before:**

```typescript
import { StyleSheet, SafeAreaView } from 'react-native';

return (
  <SafeAreaView style={styles.container}>
    <WebView ... />
  </SafeAreaView>
);
```

**After:**

```typescript
import { StyleSheet, View, StatusBar } from 'react-native';
import { useSafeAreaInsets } from 'react-native-safe-area-context';

export default function OAuthSignupScreen() {
  const insets = useSafeAreaInsets();

  return (
    <View style={styles.container}>
      <StatusBar barStyle="light-content" />
      {/* 상단 safe area */}
      <View style={[styles.topSafeArea, { height: insets.top }]} />
      {/* WebView 콘텐츠 */}
      <WebView ... />
      {/* 하단 safe area */}
      <View style={[styles.bottomSafeArea, { height: insets.bottom }]} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#0f0f10',
  },
  topSafeArea: {
    backgroundColor: '#0f0f10',
  },
  bottomSafeArea: {
    backgroundColor: '#0f0f10',
  },
  webview: {
    flex: 1,
  },
});
```
