## 환경변수 관리 방식

EAS는 세 가지 기본 환경을 제공합니다:

| 환경 | 빌드 프로필 | 용도 |
|------|------------|------|
| `development` | development | 개발용 빌드 |
| `preview` | preview | 내부 테스트용 |
| `production` | production | 스토어 배포용 |

> 환경변수는 빌드 프로필과 자동으로 매핑됩니다.

---

## 등록한 환경변수 목록

| 변수명 | 설명 | Visibility |
|--------|------|------------|
| `EXPO_PUBLIC_WEB_URL` | WebView에서 로드할 웹 URL | plaintext |
| `EXPO_PUBLIC_API_URL` | 백엔드 API URL | plaintext |
| `KAKAO_NATIVE_APP_KEY` | Kakao 로그인용 Native App Key | secret |

> 각 환경(development, preview, production)별로 값을 다르게 설정할 수 있습니다.

---

## EAS 대시보드에서 환경변수 등록 방법

### 1. EAS 대시보드 접속

1. [expo.dev](https://expo.dev) 접속
2. **Projects** → **growit-mobile** 선택

### 2. Environment Variables 메뉴 이동

1. 좌측 메뉴에서 **Project settings** 클릭
2. **Environment variables** 선택

### 3. 변수 추가

1. **Add Variable** 버튼 클릭
2. 다음 정보 입력:
   - **Name**: 변수명 (예: `EXPO_PUBLIC_WEB_URL`)
   - **Value**: 값 (예: URL)
   - **Environments**: 적용할 환경 선택 (development / preview / production)
   - **Visibility**: plaintext / sensitive / secret 선택
3. **Add** 버튼 클릭

### 4. 변수 수정/삭제

- 등록된 변수 옆 **...** 메뉴에서 Edit 또는 Delete 선택

---

## Visibility 옵션

| 옵션 | 설명 | 사용 예시 |
|------|------|----------|
| `plaintext` | 빌드 로그에 노출됨 | URL, 설정값 |
| `sensitive` | 빌드 로그에서 마스킹됨 | API 엔드포인트 |
| `secret` | 로그에서 완전히 숨겨짐 | API Key, 비밀번호 |

---

## 환경변수 확인 명령어 (CLI)

```bash
# 환경별 변수 목록 확인
eas env:list --environment development
eas env:list --environment preview
eas env:list --environment production

# 로컬 개발용 .env 파일 동기화
eas env:pull --environment development
```

## eas.json 상태

환경변수를 EAS 서비스에서 관리하므로 eas.json에는 `env` 섹션이 없습니다:

```json
{
  "cli": {
    "version": ">= 18.0.1",
    "appVersionSource": "remote"
  },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal",
      "ios": {
        "simulator": true
      }
    },
    "preview": {
      "distribution": "internal"
    },
    "production": {
      "autoIncrement": true
    }
  },
  "submit": {
    "production": {}
  }
}
```
