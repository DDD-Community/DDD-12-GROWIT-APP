# 02. App Store Connect 앱 등록

## 목표

App Store Connect에 앱을 등록하고 메타데이터를 입력합니다.

## 상태

✅ 완료

## 선행 조건

- [x] Apple Developer 계정
- [x] Bundle Identifier 확정 (`com.growitddd.growit-app`)
- [x] 01-프로덕션-환경변수-설정 완료

---

## 작업 내용

### 1. 앱 생성

1. [App Store Connect](https://appstoreconnect.apple.com) 접속
2. **앱** → **+** → **새 앱**
3. 정보 입력:

| 필드 | 값 |
|------|-----|
| 플랫폼 | iOS |
| 이름 | 그로잇: AI 데일리 투두앱 |
| 기본 언어 | 한국어 |
| 번들 ID | `com.growitddd.growit-app` |
| SKU | `com.growitddd.growit-app` |
| 사용자 액세스 | 전체 액세스 |

#### SKU란?

**Stock Keeping Unit**의 약자로, 앱의 내부 관리용 고유 식별자입니다.

| 항목 | 설명 |
|------|------|
| 용도 | Apple 판매/재무 보고서에서 앱 식별, 내부 관리용 |
| 노출 여부 | 사용자에게 **표시되지 않음** |
| 변경 가능 | 한 번 설정 후 **변경 불가** |
| 허용 문자 | 영문, 숫자, 하이픈(`-`), 밑줄(`_`), 마침표(`.`) |

> 번들 ID와 동일하게 설정하면 관리가 편합니다.

---

### 2. 앱 정보 입력

#### 2-1. 기본 정보

| 필드 | 예시 |
|------|------|
| 부제목 | 성장을 위한 습관 기록 |
| 카테고리 (기본) | 라이프스타일 |
| 카테고리 (보조) | 생산성 (선택) |
| 콘텐츠 권한 | 해당 없음 |

#### 2-2. 앱 설명 (한국어)

```
growit은 당신의 성장을 돕는 습관 기록 앱입니다.

[주요 기능]
• 일일 습관 기록 및 추적
• 성장 통계 및 분석
• 목표 설정 및 달성 관리

매일 조금씩 성장하는 습관을 만들어보세요.
```

#### 2-3. 키워드

```
습관,성장,기록,목표,자기계발,생산성,루틴,일일기록
```

> 키워드는 쉼표로 구분, 최대 100자

#### 2-4. 지원 URL

| 필드 | URL |
|------|-----|
| 지원 URL | `https://www.grow-it.me/support` |
| 마케팅 URL | `https://www.grow-it.me` (선택) |

---

### 3. 앱 심사 정보

#### 3-1. 로그인 정보 (소셜 로그인 테스트용)

심사관이 앱을 테스트할 수 있도록 데모 계정 정보를 제공합니다.

| 필드 | 값 |
|------|-----|
| 로그인 필요 여부 | 예 |
| 사용자 이름 | (테스트 계정 이메일) |
| 암호 | (테스트 계정 비밀번호) |

**심사 메모 예시:**
```
이 앱은 Apple 로그인과 Kakao 로그인을 지원합니다.

[Apple 로그인 테스트]
1. 앱 실행 후 "Apple로 로그인" 버튼 클릭
2. Apple ID로 로그인 진행
3. 신규 회원의 경우 닉네임 입력 후 가입 완료

[Kakao 로그인 테스트]
위 데모 계정으로 로그인해주세요.
```

#### 3-2. 연락처 정보

| 필드 | 값 |
|------|-----|
| 이름 | (담당자 이름) |
| 전화번호 | (연락처) |
| 이메일 | (이메일) |

---

### 4. 가격 및 사용 가능 여부

| 필드 | 값 |
|------|-----|
| 가격 | 무료 |
| 사용 가능 여부 | 대한민국 (또는 전 세계) |

---

### 5. 연령 등급 설정

심사 시 연령 등급 질문에 답변합니다:

| 항목 | 답변 |
|------|------|
| 폭력적 / 공포스러운 콘텐츠 | 없음 |
| 성인 / 선정적 콘텐츠 | 없음 |
| 도박 | 없음 |
| 마약 / 음주 | 없음 |
| 욕설 / 비속어 | 없음 |
| 무제한 웹 액세스 | 아니오 |

> WebView가 자체 서비스 URL만 로드하고 사용자가 임의 URL 입력 불가하므로 "아니오"로 설정
