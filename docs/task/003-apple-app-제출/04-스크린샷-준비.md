## 필수 스크린샷 사이즈

App Store는 다음 디바이스별 스크린샷을 요구합니다:

### iPhone (필수)

| 디바이스 | 해상도 | 필수 여부 |
|----------|--------|----------|
| 6.7인치 (iPhone 15 Pro Max, 14 Pro Max) | 1290 x 2796 px | ✅ 필수 |
| 6.5인치 (iPhone 11 Pro Max, XS Max) | 1242 x 2688 px | ✅ 필수 |
| 5.5인치 (iPhone 8 Plus, 7 Plus) | 1242 x 2208 px | 선택 |

> **최소 2개 사이즈 필수:** 6.7인치와 6.5인치

### 스크린샷 요구사항

- 최소 2장, 최대 10장 (사이즈당)
- PNG 또는 JPEG 형식
- 상태바 포함 가능 (선택)
- 텍스트/그래픽 오버레이 가능

## 작업 내용

### 1. 스크린샷 캡처 대상 화면

| 순서 | 화면 | 설명 |
|------|------|------|
| 1 | 로그인 화면 | 소셜 로그인 버튼 (Apple, Kakao) |
| 2 | 홈 화면 | 메인 대시보드 |
| 3 | 주요 기능 1 | 습관 기록 화면 |
| 4 | 주요 기능 2 | 통계/분석 화면 |
| 5 | 설정 화면 | (선택) |

### 2. 시뮬레이터에서 캡처

#### 2-1. 시뮬레이터 실행

```bash
# 6.7인치 (iPhone 15 Pro Max)
npx expo run:ios --device "iPhone 15 Pro Max"

# 6.5인치 (iPhone 11 Pro Max)
npx expo run:ios --device "iPhone 11 Pro Max"
```

#### 2-2. 스크린샷 캡처

**방법 1: 시뮬레이터 단축키**
```
Cmd + S
```

**방법 2: 터미널 명령어**
```bash
xcrun simctl io booted screenshot screenshot.png
```

### 3. 실기기에서 캡처 (권장)

실기기 스크린샷이 더 자연스럽습니다:

1. 기기에서 `전원 + 볼륨 업` 동시 누르기
2. 사진 앱에서 스크린샷 확인
3. Mac으로 AirDrop 전송

### 4. 스크린샷 편집 (선택)

필요시 텍스트나 그래픽 오버레이 추가:

- **도구:** Figma, Sketch, Canva
- **권장 사항:**
  - 앱 기능을 설명하는 간단한 텍스트 추가
  - 일관된 디자인 테마 유지
  - 디바이스 프레임 추가 (선택)

## App Store Connect 업로드

1. [App Store Connect](https://appstoreconnect.apple.com) → 앱 선택
2. **앱 정보** → **iOS 앱** → **1.0 제출 준비 중**
3. **미디어** 섹션에서 각 사이즈별 스크린샷 업로드
4. 드래그 앤 드롭으로 순서 조정
