# 05. 법적 문서 준비

## 목표

App Store 제출에 필요한 개인정보처리방침 및 이용약관 URL을 준비합니다.

## 상태

⬜ 대기

## 선행 조건

- [ ] 웹사이트 호스팅 환경 준비 (법적 문서 호스팅용)

---

## 필수 문서

| 문서 | 필수 여부 | 설명 |
|------|----------|------|
| 개인정보처리방침 (Privacy Policy) | ✅ 필수 | 사용자 데이터 수집/처리 방법 |
| 이용약관 (Terms of Service) | 권장 | 서비스 이용 조건 |
| 지원 URL | ✅ 필수 | 사용자 문의 페이지 |

---

## 작업 내용

### 1. 개인정보처리방침 (필수)

#### 1-1. 포함해야 할 내용

- **수집하는 정보**
  - Apple 로그인: 이메일, 이름 (사용자 선택 시)
  - Kakao 로그인: 이메일, 프로필 정보
  - 앱 사용 데이터

- **정보 사용 목적**
  - 계정 생성 및 관리
  - 서비스 제공 및 개선
  - 사용자 지원

- **정보 공유**
  - 제3자 공유 여부
  - 서비스 제공자 (예: 서버 호스팅)

- **데이터 보안**
  - 암호화 방법
  - 접근 제어

- **사용자 권리**
  - 정보 열람, 수정, 삭제 요청 방법
  - 계정 삭제 방법

- **연락처**
  - 개인정보 관련 문의처

#### 1-2. 예시 URL

```
https://www.grow-it.me/privacy
```

---

### 2. 이용약관 (권장)

#### 2-1. 포함해야 할 내용

- 서비스 설명
- 사용자 책임
- 금지 행위
- 서비스 변경/종료
- 면책 조항
- 분쟁 해결

#### 2-2. 예시 URL

```
https://www.grow-it.me/terms
```

---

### 3. 지원 URL (필수)

사용자가 문의할 수 있는 페이지:

```
https://www.grow-it.me/support
```

포함 내용:
- 자주 묻는 질문 (FAQ)
- 이메일 문의: support@grow-it.me
- 버그 신고 방법

## 문서 호스팅 옵션

| 옵션 | 장점 | 단점 |
|------|------|------|
| 메인 웹사이트 | 통합 관리 | 웹 개발 필요 |
| GitHub Pages | 무료, 간편 | 별도 도메인 필요 |
| Notion 공개 페이지 | 가장 간편 | 덜 전문적 |

---

### GitHub Pages 예시

```bash
# docs 폴더에 법적 문서 생성
mkdir -p docs/legal
touch docs/legal/privacy.md
touch docs/legal/terms.md
```

GitHub Pages 설정 후 URL:
```
https://growit-ddd.github.io/growit-app/privacy
https://growit-ddd.github.io/growit-app/terms
```

---

## App Store Connect 입력

1. [App Store Connect](https://appstoreconnect.apple.com) → 앱 선택
2. **앱 정보** → **일반 정보**
3. 다음 필드 입력:

| 필드 | URL |
|------|-----|
| 개인정보 처리방침 URL | `https://www.grow-it.me/privacy` |
| 지원 URL | `https://www.grow-it.me/support` |
