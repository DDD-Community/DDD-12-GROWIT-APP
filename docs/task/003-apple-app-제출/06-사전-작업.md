## 작업 1: 카카오 로그인 스펙 변경

백엔드 API 스펙 변경에 맞춰 카카오 로그인 요청 파라미터를 수정합니다.

### 1-1. 스펙 변경 내용

#### 변경 전 (현재)

```typescript
POST /auth/signin/kakao
{
  "idToken": "카카오 id token",
  "authorizationCode": "카카오 accessToken (잘못된 매핑)"
}
```

#### 변경 후 (새 스펙)

```typescript
POST /auth/signin/kakao
{
  "idToken": "카카오에서 발급받은 id token (필수)",
  "refreshToken": "카카오 리프레시 토큰 (필수)",
  "nonce": "id token 검증을 위한 nonce 값 (필수)"
}
```

### 1-2. 주요 변경점

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| `authorizationCode` | accessToken 전달 | **삭제** |
| `refreshToken` | 미사용 | **신규 추가** (카카오 SDK에서 획득) |
| `nonce` | 미사용 | **신규 추가** (로그인 전 생성 필요) |

### 1-3. 수정 대상 파일

| 파일 | 수정 내용 |
|------|----------|
| `src/lib/auth/KakaoAuth.ts` | nonce 생성 및 전달, refreshToken 포함 |
| `src/lib/auth/auth.ts` | `kakaoSocialLogin` 함수 시그니처 변경 |
| `src/app/(auth)/login.tsx` | 새 파라미터로 API 호출 |

### 1-4. 작업 체크리스트

- [x] `KakaoAuth.ts`: nonce 생성 로직 추가
- [x] `KakaoAuth.ts`: `KakaoLoginResult` 인터페이스에 `refreshToken`, `nonce` 추가
- [x] `KakaoAuth.ts`: `signInWithKakao` 함수에서 refreshToken 반환
- [x] `auth.ts`: `kakaoSocialLogin` 함수 파라미터 변경 (`idToken`, `refreshToken`, `nonce`)
- [x] `login.tsx`: `handleKakaoLoginSuccess` 함수에서 새 파라미터로 API 호출
- [ ] 테스트: 로그인 플로우 정상 동작 확인

### 1-6. SDK 제한사항

> ⚠️ `@react-native-seoul/kakao-login` SDK v5.4.2는 nonce 파라미터를 직접 지원하지 않습니다.
> 프론트엔드에서 nonce를 생성하여 백엔드로 전달하지만, idToken 내부에 nonce claim이 포함되지 않습니다.
> 백엔드에서 nonce 검증 방식을 별도로 구현하거나, 검증을 생략해야 할 수 있습니다.

### 1-5. nonce 생성 방법

```typescript
// crypto 또는 uuid 라이브러리 사용
import * as Crypto from 'expo-crypto';

const generateNonce = async (): Promise<string> => {
  const randomBytes = await Crypto.getRandomBytesAsync(32);
  return Array.from(randomBytes)
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');
};
```

> ⚠️ nonce는 카카오 로그인 호출 전에 생성하고, 백엔드로 전달하여 idToken 검증에 사용됩니다.

## 작업 2: Splash 이미지 변경

앱 시작 화면 이미지를 아이콘+글자가 포함된 통합 이미지로 교체합니다.

### 2-1. 변경 내용

> ⚠️ `expo-splash-screen`은 아이콘과 텍스트를 별도 요소로 표시하는 기능을 지원하지 않습니다.
> 따라서 아이콘+글자가 포함된 단일 이미지를 사용합니다.

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 이미지 | `./assets/app/icon.png` | `./assets/app/icon-splash.png` |
| 내용 | 아이콘만 | 아이콘 + 글자 |
| 크기 | - | 400 x 400 px |

### 2-2. app.config.js 수정

```javascript
// 변경 전
[
  'expo-splash-screen',
  {
    image: './assets/app/icon.png',
    resizeMode: 'contain',
    backgroundColor: '#000000',
  },
],

// 변경 후
[
  'expo-splash-screen',
  {
    image: './assets/app/icon-splash.png',
    resizeMode: 'contain',
    backgroundColor: '#000000',
  },
],
```

### 2-3. 작업 체크리스트

- [x] `assets/app/icon-splash.png` 이미지 추가 (400x400, 아이콘+글자)
- [x] `app.config.js`에서 splash image 경로 변경
- [x] 로컬 테스트: `npx expo start --clear`
- [x] Splash 이미지 정상 표시 확인
- [x] 이미지 비율 및 배경색 확인
