## 작업 내용

### 1. 제출 전 체크리스트

#### 1-1. 코드 확인

- [ ] 모든 변경사항 커밋 완료
- [ ] main 브랜치에 머지 완료
- [ ] console.log, 디버그 코드 제거
- [ ] 프로덕션 환경변수 정상 작동 확인

#### 1-2. 설정 확인

```bash
# eas.json 설정 확인
cat growit-mobile/eas.json

# app.config.js 확인

```

| 항목 | 확인 |
|------|------|
| 앱 이름 | `growit` |
| 버전 | `1.0.0` |
| Bundle ID | `com.growitddd.growit-app` |

---

### 2. 프로덕션 빌드 생성

```bash
cd growit-mobile

# iOS 프로덕션 빌드
eas build --platform ios --profile production
```

빌드 과정:
1. EAS 서버에서 빌드 시작
2. 코드 서명 (자동 또는 수동)
3. `.ipa` 파일 생성
4. 빌드 완료 알림

> 빌드 시간: 약 15-30분

#### 2-1. 빌드 상태 확인

```bash
# 빌드 목록 확인
eas build:list

# 특정 빌드 상태 확인
eas build:view
```

#### 2-2. 빌드 다운로드 (선택)

```bash
# 빌드 아티팩트 다운로드
eas build:download --platform ios
```

---

### 3. App Store Connect 제출

#### 3-1. EAS Submit으로 제출

```bash
# 가장 최근 빌드 제출
eas submit --platform ios --profile production --latest

# 또는 특정 빌드 ID로 제출
eas submit --platform ios --profile production --id <BUILD_ID>
```

#### 3-2. 제출 확인

1. [App Store Connect](https://appstoreconnect.apple.com) 접속
2. **앱** → **growit** 선택
3. **TestFlight** 탭에서 빌드 확인
4. 처리 완료까지 대기 (약 5-30분)

---

### 4. 심사 제출

App Store Connect에서 빌드가 처리되면:

1. **앱 정보** → **iOS 앱** → **1.0 제출 준비 중**
2. **빌드** 섹션에서 업로드된 빌드 선택
3. 모든 필수 정보 확인:
   - [ ] 스크린샷 업로드 완료
   - [ ] 앱 설명 입력 완료
   - [ ] 개인정보처리방침 URL 입력
   - [ ] 심사 정보 (테스트 계정) 입력
   - [ ] 연령 등급 설정
4. **심사를 위해 제출** 클릭

---

### 5. 심사 대기

| 단계 | 상태 | 예상 시간 |
|------|------|----------|
| 제출됨 | Waiting for Review | - |
| 심사 중 | In Review | 24-48시간 |
| 승인됨 | Ready for Sale | - |
| 거절됨 | Rejected | 사유 확인 후 재제출 |

#### 5-1. 거절 시 대응

1. 거절 사유 확인 (Resolution Center)
2. 필요한 수정 진행
3. 새 빌드 생성 및 재제출

---

## 명령어 요약

```bash
# 1. 프로덕션 빌드
eas build --platform ios --profile production

# 2. App Store Connect 제출
eas submit --platform ios --profile production --latest

# 3. 빌드 및 제출 한 번에 (옵션)
eas build --platform ios --profile production --auto-submit
```
